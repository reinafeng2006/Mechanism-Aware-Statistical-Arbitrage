### Branch A — governance-limited source-contract amendment

Authorize Sina raw/unadjusted daily observations for a bounded formal acquisition role despite `FALLBACK ONLY` qualification. The amendment must preserve: original payloads; endpoint/request/retrieval hashes; daily schema acceptance; external unit documentation; explicit absence of source vintages/SLA; `UNKNOWN MISSINGNESS`; no qfq/hfq canonical use; no silent patching; coverage checks; stop-on-schema/hash/field failure; and a future replacement/reconciliation obligation if a stronger canonical source becomes available.

No branch is selected by this proposal.

This branch is justified only if the quoted source materially closes frozen contract gaps relative to Sina; field richness alone is insufficient.
