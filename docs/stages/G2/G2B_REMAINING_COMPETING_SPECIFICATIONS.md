# G2B Remaining Competing Specifications

Status: **APPROVED / FROZEN — 2026-09-08**

These alternatives remain deliberately open for later frozen development/OOS comparison:

1. **Information architecture:** P0 primary baseline versus P0 plus separately measured P1 incremental layer.
2. **Relationship object:** simple raw distance/correlation baselines versus exposure, residual/conditional, stochastic, cointegration and signed-response representations. Non-equivalent constructs must not be merged into a Pair Score.
3. **Pooling:** N0 is the simpler strongly pooled baseline and N1 is the mandatory pair-specific challenger under the same frozen fair-comparison semantic target, P0/P1 information architecture, PIT boundary, evaluation period, relationship-level objective, outcome-exclusion discipline and anti-circularity rule. Neither is selected. N2 remains blocked pending escalation evidence.
4. **Abnormality:** A-MAG/A-SIGN core with A-RES competing; A-TIME and A-SUM optional. Multidimensional state remains primary.
5. **M1:** UR0 versus UR1 as implementable alternatives; UR2 optional only with non-duplicative lineage.
6. **M2:** MP0 morphology plus MP1 accessible context as implementable branches; MP2 optional; MP3 blocked/research-only.
7. **Rejection:** R0 and R3 core channels; R1 competing event channel; R2 optional structural-link layer.
8. **Uncertainty:** U0 versus/with U4; U1/U2 optional pending belief architecture; U3 blocked until decision design.
9. **Timing:** coarsest clock that preserves signed ordering versus finer optional clocks. No actual frequency is selected.

Later protocol design—not G2B—must define fair comparisons, metrics, windows, estimators and OOS rules.

Distance and correlation enter only as simple baseline representations: `distance ≠ pair validity` and `correlation ≠ normal relationship`.
