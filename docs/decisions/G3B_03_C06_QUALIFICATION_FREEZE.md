# G3B-03 C06 Qualification — Freeze Decision

Decision ID: **G3B-03**  
Date: **2026-09-08**  
Status: **ACCEPTED / FROZEN**

Accepted conclusion: **`QUALIFIED WITH DOCUMENTED LIMITATIONS — SUFFICIENT FOR A FORMAL ACQUISITION PROPOSAL`**.

## Frozen C06 PIT reconstruction principles

- Historical membership uses actually published historical classification snapshots.
- A classification becomes usable only from its defensible `publication_time` / `available_time`.
- Quarter/half-year period labels are never backfilled to the beginning of the labeled period.
- Between releases, the latest publicly available classification may be carried forward with explicit staleness state.
- Taxonomy and version are preserved.
- C06 joins to C01 listing/delisting/security-identifier history.
- Current constituents are never retrospectively substituted for historical membership.

## Researcher decisions incorporated

1. “Machinery” is represented by a bounded versioned `MACHINERY_INDUSTRY_SCOPE_MAP`, not one timeless code. Ambiguity is surfaced for review and cannot be optimized using future pair availability, sample size, returns or outcomes.
2. `2013-01-07` is the earliest currently qualified C06 PIT availability boundary, **not** the frozen formal research start date.
3. Classification uses `PIT carry-forward + explicit staleness state`, including snapshot ID, publication/available time, taxonomy version, `classification_age` and stale-gap indicator. No numerical exclusion threshold is frozen. The audited 2021 Q3–2023 H1 publication interval is preregistered as a robustness/validity concern.
4. C06 no longer blocks preparation of formal acquisition. The scope map and final acquisition-contract reconciliation must precede acquisition authorization.

`PIT-valid classification ≠ necessarily economically current classification`.

## Unchanged boundary

No provider, data download, research start date, staleness threshold, pair/model/factor choice or empirical work is authorized by this decision.
