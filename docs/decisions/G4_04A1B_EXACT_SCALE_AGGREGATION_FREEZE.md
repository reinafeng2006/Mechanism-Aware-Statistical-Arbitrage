# G4-04A1b Exact Scale & Aggregation Freeze

Decision date: 2026-09-10
Status: **APPROVED / FROZEN**

## Selected primary architecture

- MAD is the primary robust historical PIT scale for the same directional-response quantity;
- standard deviation is the preregistered quadratic normalization robustness check;
- separate `i -> j` and `j -> i` scales remain mandatory;
- candidate-neutral relative scale-quality qualification is selected; no universal epsilon floor;
- within-direction median is primary;
- pair-level evidence retains an equal-status directional vector;
- equal-pair median is the primary representation-level aggregate;
- temporal median-vector is primary and preserves consistency, dispersion, severe failure, and support;
- AG2 separately guards absolute adequacy failure, comparative reversal, and structural/support failure without producing a score.

IQR, RMS-about-median, trimmed means, and mean-vector remain registered sensitivity/reference candidates only and cannot enter primary selection. Exact cutoff values remain unresolved for G4-04A1c. No computation is authorized.
