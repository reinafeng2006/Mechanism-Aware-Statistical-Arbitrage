# M1-001 Paper Guide — Cohen & Frazzini (2008)

**为什么审阅：** 判断已知 customer–supplier link 上的 lead-lag 何时可以支持“延迟信息吸收”而不只是相关性。

**先备概念：** directional economic link、public information、limited attention、PIT linkage vintage。

**方法：** 用已披露的重要 customer–supplier 关系、滞后 linked-firm returns/news，并控制 own、industry 与 cross-industry momentum；另考察共同基金持有/交易的异质性。

**项目相关证据：** 支持 source/link/direction/timing 与 peer-under-response 一起构成候选 M1 链条。

**关键限制：** 不能给单个事件贴 causal-attention 标签；private information、own news、common shock、risk、liquidity 与 stale link 都竞争解释。共同持有的披露滞后通常不适合直接作 event-time 输入。

**改变了什么：** 允许 G2 保留 P/C/R 的链接、来源、时点和反证构念；禁止用 generic lead-lag 或未来 follower return 作为 M1 输入。

**Ancestry:** M1-001; CL-M1-001. 教学说明，不构成证据。
