# Research Decision Walkthrough: From Lead-Lag to Candidate M1

**Paper evidence →** M1-001 的披露方向性客户—供应商 link，及 M1-008 的 timestamped supply-chain news，均比 generic lead-lag 提供更多来源与路线信息。

**Tempting interpretation →** source 先涨、peer 后涨，所以 peer 当时一定注意力不足。

**Identification limitation →** 可能有 private/pre-release diffusion、own news、共同冲击、link backfill 或错误匹配；研究也不识别单个事件的 attention state。

**Permitted conclusion →** 只有 PIT link + source/event provenance + economic direction + peer未提前吸收 + rival/leakage checks 共存时，才是 candidate M1；未来 catch-up 只做验证。

**Prohibited conclusion →** 不可用 observed lead-lag、leader size、新闻 sentiment 或 future follower return 单独贴 M1 标签。

**Ancestry:** M1-001, M1-008; CL-M1-001, CL-M1-003. 教学说明，不构成证据。
