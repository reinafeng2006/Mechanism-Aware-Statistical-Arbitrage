# M1: Delayed Information Incorporation / Limited Attention

**一句话直觉：** 看到 leader 先动、peer 后动，只说明 lead-lag；只有知道信息从哪里来、为何应沿该关系传递、何时公开、peer 在此时仍未反映，才可把它视为候选 M1。

## Definition and core logic

`PIT directional economic link → timestamped source public event/response → peer under-response through decision time → candidate M1 → later catch-up only as validation`。

## Measures / does not measure

它组织 M1 的识别要求：方向性 link、source identity、first-public timestamp、source/peer contemporaneous response、peer own-news 与 leakage/rival checks。它不测量个体投资者注意力状态，也不把 future peer return 变成事件时点输入。

## Assumptions and nearby concepts

要求关系和事件在 decision time 已知，且方向与经济传导相符。与 generic lead-lag 不同；与 M2 flow pressure、M0 structural divergence 也不同，后者仍是竞争解释。
