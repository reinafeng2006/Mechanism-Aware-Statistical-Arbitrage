# M2: Temporary Liquidity / Flow Pressure

**一句话直觉：** M2 不是“价格后来反转”，而是当时有可信的暂时压力来源、市场吸收条件和排除信息驱动解释的证据。

## Defined concepts and boundary

Pressure-source evidence、market/liquidity-state evidence、abnormal price/flow response 与 rival-information checks 可以共同更新 M2 belief。`belief_(t+1)=update(belief_t,new_PIT_evidence_(t+1))` 仅为 **ILLUSTRATIVE / UNAUTHORIZED**，不是 classifier。

## Measures / does not measure

calendar/settlement timing、PIT holdings/flow lineage、price/volume/turnover/quotes、signed flow 与 permanent/transitory decomposition 都可能提供局部信息。它们不单独识别 forced motive；generic flow 可嵌入 realized return，volume/turnover 也不等于 M2。

## M1 comparison

M1：peer 可能反应不足，候选验证是 follower catch-up。M2：shocked/source asset 可能偏离过大，候选验证是 source normalization。later reversal 对两者都只是 validation。
